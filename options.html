When an HTTPS site is blocked by AdGuard Home, the extension catches the navigation error, asks AGH whether the domain is filtered, and shows an Unblock page. It reuses your existing logged-in AdGuard Home session — no password is stored here. Element hiding adds cosmetic rules that Firefox applies; AGH stores them but cannot inject CSS over DNS.

The extension needs an AdGuard Home tab that is logged in. If none is open, it opens an inactive AGH tab for the API request and keeps it for later unblocks. If the session expired, log in there and try again.
